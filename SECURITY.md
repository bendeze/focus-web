# Security Policy

## Supported Versions

The following table lists which versions of Focus Web currently receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |
| < 0.1   | No                 |

## Reporting a Vulnerability

We take security issues seriously. If you discover a security vulnerability in Focus Web or associated API services, please report it privately rather than creating a public issue.

To report a vulnerability:
1. Contact the maintainers privately via GitHub Security Advisories on the repository: https://github.com/bendeze/focus-web/security/advisories/new
2. Include detailed steps to reproduce the issue, proof-of-concept payloads or code if available, and any remediation suggestions.

### Disclosure Timeline

- Initial response: Within 48 hours of receipt.
- Assessment and patch: Within 14 days depending on severity.
- Public disclosure: Coordinated after a fix has been published.
